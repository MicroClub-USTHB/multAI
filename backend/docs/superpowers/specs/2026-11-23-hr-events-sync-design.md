# HR-Events -> MultiAi event sync (short design)

## Intent
HR-Events (mc/HR-Events) becomes the only place events are created. MultiAi
keeps its own `events` row (photos, join codes hang off it) but is told about
each event by HR-Events and no longer creates events itself.

## Goals
- When HR creates an event in HR-Events, MultiAi gets a matching event.
- MultiAi has no public/staff "create event" endpoint any more.
- Existing HR-Events events (no MultiAi copy yet) get synced by a backfill.
- Each synced event gets a join `event_code` generated by MultiAi. Staff read
  the code in the MultiAi dashboard and send it to attendees manually; attendees
  join with it.

## Non-goals
- Syncing edits/archive from HR-Events (create only, for now).
- Automatic code delivery to attendees.
- HR-Events storing an event code (it has none; MultiAi owns it).

## Approaches
1. HTTP push + outbox retry from HR-Events (chosen). Fits MCDI-style
   service-key pattern; no new infra.
2. NATS publish: needs HR-Events NATS access + new library (forbidden by its
   stack rules).
3. MultiAi polls HR-Events: delayed, needs service read endpoint.

## Design
MultiAi:
- Remove `POST /events/` and the `EventCreate` request path.
- Migration: `events.external_id` (text/uuid, unique, nullable);
  `events.created_by` becomes nullable (system-created events).
- New `POST /internal/events`, authenticated by a shared service key from
  settings (header check, constant-time compare). Body: HR event id, name,
  starts_at, ends_at. Idempotent upsert on `external_id`; generates
  `event_code` on first insert only; returns the event with its code.
- Backfill match: row with `external_id` null and same name + event_date gets
  `external_id` set, keeping its code/photos. Otherwise insert.

HR-Events (needs owner approval: outside phase 1 S1-S14):
- On event create, enqueue a notification to MultiAi (outbox + retry).
- One-off backfill script that sends all existing events through the same call.

## Left to the builder
Exact field/env names, outbox shape, retry timing, tests.
